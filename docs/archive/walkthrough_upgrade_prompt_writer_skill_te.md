# Walkthrough: Prompt-Writer Parallel Subagent Orchestration Upgrade

## Overview
We upgraded the `prompt-writer` skill (located in `skills/prompt/` and globally symlinked to `~/.gemini/config/skills/prompt-writer/`) to ensure that:
1. Rewritten prompts generated by the skill embed imperative native Antigravity `<SUBAGENT_ORCHESTRATION>` directives using `invoke_subagent` instead of failing inline or referencing legacy offline Python scripts (`execute_pipeline.py`).
2. The `prompt-writer` rewriter itself mandates concurrent background scouting (`TypeName: "research"`, `Workspace: "share"`) across the codebase, web, and documentation without falling back to inline exploration on the main thread.
3. Subagent type names and workspace isolation modes strictly conform to native Antigravity specifications (`TypeName: "research"` for read-only exploration/review; `TypeName: "self"` for code-generating worker subagents in isolated `Workspace: "branch"` environments).
