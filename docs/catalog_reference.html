📚 Skills Catalog Reference & Attribution Matrix

Comprehensive dictionary, cluster categorization, execution triggers, and upstream attribution lineage for every skill in Agent Skill Forge.

---

🌟 1. Core Universal Action Verbs (4 Clusters)

The Core Skills can be installed individually or in functional clusters using bash scripts/install.sh --clusters <ids> (e.g. --clusters c3 or --content).

📐 Cluster C1: Planning, Specification & Swarm Execution (plan-spec)

Grounds requirements, gathers intent, conducts Socratic alignment, plans dependency DAGs, and executes autonomous swarms.

Cluster Slug Invocations & Triggers Execution Mode Scope & Capabilities
C1 prompt /prompt, /prompt-writer User Slash Decomposes complex tasks, vague ideas, or multi-step goals into intent directives and DAG task graphs (task_graph.json).
C1 grill /grill, /interview User Slash 1-question Socratic interview with attached hypotheses to clarify requirements, architecture, or design tradeoffs until 95% confident.
C1 spec /spec, auto on new features Autonomous Writes structured, doc-cited specifications with explicit non-goals before executing code.
C1 plan /plan, /planning Autonomous Slices complex features, refactors, or projects into small, vertically sliced tasks with verifiable checkpoints.
C1 work /work User Slash Coordinates autonomous parallel swarms with Sentinel oversight, dispatch-only orchestration, competitive branching tournaments, and adversarial verification.
C1 h2o /h2o Autonomous Lean sequential swarm: grills to >= 90% confidence, freezes binary done criteria, then runs a Hydrogen planner and implementer against Opus adversarial gates (plan, functional, code, security), each capped at 3 NOT GOOD verdicts before the user decides.

🧪 Cluster C2: Quality & Verification (test-review)

Enforces TDD, static verifiers, blinded judge rubrics, grounded code and security reviews, the PR and GitHub issue loops, and slop elimination.

Cluster Slug Invocations & Triggers Execution Mode Scope & Capabilities
C2 test /test, auto during coding Autonomous Enforces writing failing tests first to prove bug reproduction and verify new feature behavior (TDD & Prove-It).
C2 verify /verify, /ega, /expectation-harness Autonomous Dual-layer verification running deterministic static check scripts and blinded multi-persona dynamic judge rubrics.
C2 review /review, pre-merge Autonomous Runs the repo's linters and type checkers, then reviews diffs across eight axes (scope/architecture, correctness, security, reliability, performance, data integrity, tests, observability) plus style, emitting schema-validated findings (P0–P3, nit) and SARIF.
C2 security-review /security-review Autonomous Runs semgrep, gitleaks, osv-scanner, trivy, actionlint, zizmor and native audits as leads, then confirms each against a six-element finding test grounded in OWASP Top 10 2025, ASVS 5.0, CWE Top 25, OWASP LLM and API Top 10, and GitHub Actions hardening. Same findings schema and P0–P3 scale as review.
C2 pr-review-loop /pr-review-loop Autonomous Works the review threads on your PR until the pr-guardian/verdict gate is green: fix and reply with the SHA, push back with /ai-review wontfix:, or escalate to a human. Resolves a thread only after pr-guardian verifies the fix or accepts the pushback.
C2 issue-loop /issue-loop, /fix-issue, /fix-issues Autonomous Drives open GitHub issues through five gated stages: redacted, injection-framed intake and triage, file-disjoint track planning, TDD red-green fix on a feature branch, 8-axis review plus security and cross-family verification gate, and PR creation (Fixes vs Refs for partial fixes) with optional pr-review-loop handoff.
C2 unslop /unslop, /deslop Auto / Slash Strips AI smells, promotional bloat, and needless words from prose, docs, code comments, commit messages, analyses, and UI copy. Leaves code logic alone.

🎨 Cluster C3: Content, Creative & Authoring (content-creative)

Designs step-by-step developer tutorials, extracts human writing cadence, profiles how you want agents to write back, drafts articles, synthesizes diagrams, produces distinctive human-grade reports and briefs, and turns technical dossiers into grounded nonfiction field books.

Cluster Slug Invocations & Triggers Execution Mode Scope & Capabilities
C3 codelab /codelab, /codelab-creator User Slash Scaffolds and validates interactive step-by-step developer tutorials, workshops, and guides formatted for claat.
C3 human-voice /human-voice, /extract-human-voice User Slash Scans developer tool conversation logs, scrubs PII, and extracts authentic human writing style markers.
C3 voice-register "in my voice", outward text under your name Autonomous Resolves a voice profile (.local.md > ~/.gemini/personas/default/ > template) and applies the matching channel register (R1–R5) to text sent under your name.
C3 cognitive-profiler /cognitive-profiler User Slash Profiles how you prefer to be written to from your AI-tool logs, and turns it into harness instructions.
C3 image-gen /image-gen (legacy alias: /image-gen-expert) Auto / Slash Generates verified images, diagrams, multi-panel comics, and sequential timelines via gemini-api CLI (gemini-nano-banana-2.1, gemini-3-pro-image).
C3 atelier auto on reports, briefs, and digests Auto / Slash Produces subject-grounded, scannable reports, briefs, digests, and documents with strong hierarchy, tables, and diagrams. Avoids generic AI aesthetics.
C3 chronicle /chronicle, @chronicle Auto / Slash Turns technical reports and dossiers into Gladwell/Grant nonfiction with evidence badges and a Field Notebook.
C3 video-gen /video-gen, /omni-video Auto / Slash Generates arbitrary-length videos (3s..3600s+), chains anchored keyframes (image-gen), mixes ducked -14 LUFS audio, overlays captions/cards (vidkit/sound or standalone ffmpeg), and verifies with ffprobe + Argon.
C3 audio-gen /audio-gen, /music-gen, /sfx-gen, /tts-gen Auto / Slash Generates verified BGMs/songs (lyria-3.5), Gemini 3.8 TTS narration/dialogue (speech_metadata + Chunk-1 pinning), /v1beta/voices design/replication, Chirp 3: HD, foley/stingers, and -14 LUFS 2-pass mixes.

📚 Cluster C4: Knowledge & Governance (docs-governance)

Cluster Slug Invocations & Triggers Execution Mode Scope & Capabilities
