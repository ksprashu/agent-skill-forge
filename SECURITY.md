# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of `agent-skill-forge` seriously. If you believe you have found a security vulnerability in any skill, script, or configuration:

1. **Do not create a public GitHub issue.**
2. Report the details via GitHub Security Advisories or email the maintainers privately.
3. Include:
   * Description of the vulnerability.
   * Steps to reproduce or proof-of-concept.
   * Affected skills or scripts.

We will acknowledge your report within 48 hours and work with you on a patch and responsible disclosure timeline.
