## Meet Your New Best Friend (Gemini CLI)

Duration: 5:00

It’s time to meet the star of the show: **Gemini CLI**! 

<img src="img/gemini_cli_comic.png" alt="Malti and Raggy's guide to Gemini CLI" width="624.00" />

Gemini CLI is your AI-powered assistant for the command line. It helps you:
- **Build Faster:** Generate code and UI instantly.
- **Automate Work:** Handle deployments and cloud tasks with ease.
- **Expert Guidance:** Get help with APIs and architecture directly in your terminal.

> aside positive
> **Want to be a Pro?**
> Check out the **[Gemini CLI Hands-On Codelab](https://codelabs.developers.google.com/gemini-cli-hands-on)** for a deep dive!

### **1. Install Gemini CLI**

**Using Cloud Shell?**
Good news! Gemini CLI is already installed and ready to go. No setup needed!

**Using your Local Terminal?**
You can install it globally via npm:
```bash
# Copyright 2026 Google LLC.
# SPDX-License-Identifier: Apache-2.0

npm install -g @google/gemini-cli
```

### **2. Launch and Say Hi!**

Launch the CLI by typing:
```bash
# Copyright 2026 Google LLC.
# SPDX-License-Identifier: Apache-2.0

gemini
```

**First Run?**
The CLI will guide you through a quick login. Raggy recommends using your **personal Gmail account** for the best free quotas!

Once you see the `gemini>` prompt, try it out:
```bash
Hi
```

### **3. Essential Commands**

*   **`/help`**: See everything Gemini can do.
*   **`/quit`**: Exit back to your normal terminal.

> aside positive
> **Malti's Pro Tip:** Keep your Gemini terminal open in its own tab. You'll use it to generate code while your other terminal runs the app!
