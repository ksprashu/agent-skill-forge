# Assets Directory

This directory is intended for reference images used to maintain brand or style consistency across generated assets. 

For example, you might place a `brand-style-guide.png` or a mood board image here to pass to the `--references` flag in `scripts/image_gen.py`. This ensures that any infographics, diagrams, or hero images generated for a specific project share a cohesive visual language.

*Note: Legacy character-specific reference images have been removed to encourage dynamic, from-scratch asset generation based on the needs of the content being written.*
