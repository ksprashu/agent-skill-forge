# Prompt Recipes & Design Patterns for Image Generation

This reference guide provides production-tested prompt recipes and layout patterns for generating visual assets using Gemini image generation models (`gemini-3-pro-image-preview`).

---

## 🎨 1. Hero Images (16:9 Banners & Headers)

### Tech Corporate / Cloud Architecture Hero
```text
A cinematic, wide-shot hero image representing modern cloud architecture. Sleek modern 3D floating nodes connected by glowing fiber-optic data streams. Palette of deep slate blue, electric indigo, and warm orange accents. Soft studio ambient lighting, shallow depth of field, subtle volumetric glow, clean composition with negative space on the right for text overlay. Aspect Ratio 16:9.
```

### Developer Tooling / Open Source Banner
```text
A vibrant isometric 3D illustration depicting automated CI/CD pipelines and software engineering workflow. Glossy clay render aesthetic, neon mint and cyan accents on a dark charcoal background. Soft volumetric lighting, clean geometric layout, high contrast. Aspect Ratio 16:9.
```

## 📊 2. Architecture Diagrams & Flowcharts (4:3 / 1:1)

### Clean Microservices Flowchart
```text
Flat vector diagram illustrating a microservices architecture. Central API gateway connecting to three distinct service blocks labeled 'Auth Service', 'Payment Service', and 'User DB'. Clean minimalist layout, solid light gray background, corporate modern colors (navy blue, teal, coral). Readable typography, crisp vector lines. Aspect Ratio 4:3.
```

## 📈 3. Infographics & Data Visualizations

### Key Metric / Statistics Callout
```text
A modern minimalist infographic card highlighting data growth. Features a bold prominent chart graphic with a sleek dark mode theme, electric green line graph trending upward. Clean layout, high contrast, studio light backdrop. Aspect Ratio 1:1.
```
