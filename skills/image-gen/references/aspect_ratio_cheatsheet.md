# Aspect Ratio & Layout Reference Cheatsheet

Use this guide to map specific visual asset requirements to optimal aspect ratio (`--ar`) configurations.

| Asset Category | Target Use Case | Recommended Aspect Ratio (`--ar`) | Key Prompt Keywords |
| :--- | :--- | :---: | :--- |
| **Hero Banners** | Blog headers, article banners, documentation covers | `16:9` | *Cinematic wide-shot, focal point on left/center, negative space for titles* |
| **Inline Diagrams** | Architecture diagrams, sequence flows, data maps | `4:3` or `1:1` | *Clean vector layout, crisp typography, clear connectors, light/neutral background* |
| **Infographics** | Process steps, multi-point summaries, statistics | `4:3` or `3:4` | *Structured grid, high contrast callouts, reads "LABEL", legible layout* |
| **Spot Icons** | Feature highlights, callout boxes, bullet avatars | `1:1` | *Isolated subject, centered composition, 3D clay or flat vector, solid backdrop* |
| **Social / Mobile** | Mobile cards, social preview thumbnails | `1:1` or `9:16` | *Bold focal subject, high contrast colors, visible at small dimensions* |

## Aspect Ratio Dimensions Table

| Aspect Ratio Flag | Typical Resolution (px) | Orientation | Ideal Placement |
| :---: | :---: | :---: | :--- |
| `16:9` | 1344 x 768 | Landscape (Wide) | Web page hero, YouTube thumbnail, slide header |
| `4:3` | 1152 x 864 | Landscape (Standard) | Article body illustration, technical diagram |
| `1:1` | 1024 x 1024 | Square | Inline graphic, avatar, spot illustration, icon |
| `3:4` | 864 x 1152 | Portrait | Tall infographic, step-by-step workflow |
| `9:16` | 768 x 1344 | Portrait (Tall) | Mobile story, vertical poster |
