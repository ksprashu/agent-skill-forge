## Overview

`chronicle` transforms technical dossiers, system architectures, research papers, and strategic playbooks into gripping long-form nonfiction narratives styled after Malcolm Gladwell and Adam Grant. It pairs rich storytelling with Atelier Literary Edition book typography, evidence badges (`[P]`, `[D]`, `[A]`, `[U]`), SVG visual exhibits, and interactive Field Notebook checklists.

## Key Artifacts Produced

- **Interactive HTML Storybook / Field Book**: Single-file web app featuring dark/light reading modes, chapter progress tracking, margin evidence lenses, and persistent to-do state.
- **Canonical Narrative Google Doc**: Standardized Google Doc saved directly to workspace outputs for long-term archiving and cross-device reading.
